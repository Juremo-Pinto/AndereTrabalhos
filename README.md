# LPR2026

Repositório destinado às **atividades e projetos desenvolvidos durante as aulas do professor Andery**.

Este repositório reúne exercícios, práticas e projetos realizados ao longo das aulas, servindo também como um registro da minha evolução durante o curso de **Desenvolvimento de Sistemas**.

---

## Sobre o projeto

Este é um repositório **acadêmico**, criado para organizar as atividades desenvolvidas em sala de aula.

Cada pasta representa uma aula ou conjunto de atividades:

```text
LPR2026/
├── Aula2/
├── Aula4/
├── Aula5/
├── Aula6/
├── Aula7/
├── Aula8/
├── Aula9/
├── .gitignore
├── .gitattributes
├── LICENSE
└── README.md
```

As atividades podem envolver diferentes conceitos e tecnologias estudados durante o curso.

---

## Objetivos

* Praticar programação através de exercícios;
* Aplicar os conceitos apresentados em aula;
* Experimentar diferentes tecnologias;
* Organizar as atividades acadêmicas;
* Acompanhar minha evolução como desenvolvedor.
